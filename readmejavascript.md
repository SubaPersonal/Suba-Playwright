What is JavaScript?
=====================
- JavaScript is a high-level, dynamically typed programming language used to make web applications interactive and dynamic.
- It can run in the browser as well as on the server using environments like Node.js.
- In automation testing, JavaScript is commonly used with tools like Playwright to write test scripts,
  handle browser actions, create reusable functions, work with data, and perform validations.

Naming Conventions in JavaScript:
===================================
File Names :
---------------
    File name starts with lowercase letter

camelCase  
----------

    Start with a lowercase letter and every subsequent letter as uppercase without space and special character

    Example:
    --------

    loginPage.js
    userProfile.js

Pascal Case:
-----------
    Start with uppercase  
    Example:
    --------
    Class LoginPage{ }

What is an Interpreter?
========================

An interpreter reads the source code line by line, 
converts it into machine-understandable instructions, and executes it immediately.

A compiler converts the entire source code into machine code before execution.
